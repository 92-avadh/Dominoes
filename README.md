# Dominoes — Unity Mobile Game MVP

A Dominoes mobile game built with Unity 6, C#, and UI Toolkit.

## Features
- **UI Toolkit Presentation**: Skeuomorphic, responsive mobile UI.
- **Game Modes**: Classic Draw, Block, All Fives, and Heads-Up Duel.
- **Gameplay Systems**: Move validation, turn management, pass/draw rules, smart-fit 2D board scaling, and bot AI.
- **Tutorial & Guidance**: Interactive guide with mascot assistance and hint capabilities.
- **Customizable Experience**: Audio, sound effects, and haptic feedback toggles.
